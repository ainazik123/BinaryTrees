
Invert Binary Tree

Description
Invert a binary tree by swapping its left and right children.

Algorithm
1. Check if the node is null.
2. Swap the left and right children.
3. Invert the left subtree.
4. Invert the right subtree.
5. Return the root.

Example
Input:[4, 2, 7, 1, 3, 6, 9]

Output:[4, 7, 2, 9, 6, 3, 1]

Complexity
- Time: O(n)
- Space: O(h)
