
Binary Tree Inorder Traversal

Description
Return the inorder traversal of a binary tree.

Algorithm
1. Check if the node is null.
2. Visit the left subtree.
3. Add the current node value.
4. Visit the right subtree.

Example
Input:[1, null, 2, 3]

Output:[1, 3, 2]

Complexity
- Time: O(n)
- Space: O(n)
